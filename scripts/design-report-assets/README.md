# Design report fonts

Self-hosted Latin WOFF2 subsets of Inter (weights 400–650) and Instrument Serif
(regular), downloaded from Google Fonts on 2026-11-24. Both use the SIL Open Font
License; the original copyright and license texts are included here.

Source: https://fonts.google.com/specimen/Inter and
https://fonts.google.com/specimen/Instrument+Serif. The generator embeds these files
as data URLs so a saved report opens offline without external font requests.
